Project 01 • Flagship Web Application

PathFinder • Demystifying Student Tech Careers

An interactive career exploration platform engineered with vanilla web technologies to help freshmen navigate the overwhelming landscape of tech specializations with personalized, actionable study roadmaps.

Project Role Solo Designer & Developer
Timeline First Year • 2026
Key Stack Semantic HTML5, CSS Grid, Vanilla JS
Links GitHub Repository ↗

The Problem • Freshman Career Paralysis

When entering computer science as a freshman, students are bombarded with endless conflicting advice: "Learn Rust!", "Focus on AI agents!", "Start with Web Dev!", "Solve 500 LeetCode problems!"

This fragmentation creates severe imposter syndrome and career paralysis. Most students don't know what different roles actually feel like in daily practice or how their natural strengths align with specific trajectories.

My Approach • Zero-Bloat, Self-Reflective UI

Rather than building a heavy full-stack application with user logins and databases, I deliberately chose a lightweight, zero-dependency browser application that any student could open on a laptop or smartphone in seconds.

I architected a 3-question reflective assessment that evaluates cognitive preferences: visual-spatial thinking (Web Engineering), pattern recognition and data curiosity (AI/ML), or deep algorithmic puzzles and systems architecture (Backend & Logic).

✦ Personalized Student Roadmap

Matched Path: Creative Frontend & Web Engineer

You bridge human aesthetics with engineering logic. Recommended starting point: Semantic HTML5, CSS Grid & Flexbox, modern JavaScript ES6+, and component thinking.

Phase 1: Foundations

HTML semantics, responsive design, JavaScript DOM manipulation, Git version control.

Phase 2: First Projects

Build 3 standalone apps: a personal portfolio, a dynamic API dashboard, and an interactive quiz.

Phase 3: Deepening

Framework mastery, state architecture, accessibility (WCAG), performance optimization.

Key Features

  • ✦ Dynamic Trajectory Engine: Evaluates responses and maps student strengths to 3 major CS paths.
  • ✦ Three-Phase Roadmaps: Step-by-step guidance broken into Foundations, First Projects, and Deepening.
  • ✦ Curated Vault: Direct links to premier free learning materials (CS50, MDN, Python Docs).
  • ✦ Adaptive Screen Design: Fluid experience whether viewed on desktop widescreen or transit smartphone.

Technologies Used

HTML5 Semantics CSS Grid & Flexbox Vanilla JavaScript (ES6+) DOM Manipulation Responsive Media Queries Web Accessibility (a11y)

What I Learned

Engineering Reflection

1. You don't always need a heavy framework: Building this entirely in vanilla JavaScript gave me deep appreciation for the native DOM API, event delegation, and clean CSS layout techniques.

2. User empathy is everything: Friends who used PathFinder didn't care about the complexity of the code—they cared that they finally had a 3-step plan instead of 50 open browser tabs.

3. Mobile ergonomics: Ensuring buttons are easily clickable with thumbs and roadmap cards are readable on small screens taught me responsive design first-hand.
