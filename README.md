# My Developer Portfolio

A personal portfolio built with plain HTML, CSS and a little vanilla JavaScript. It features **PathFinder**, my student career-discovery website.

## Run it locally
Open `index.html` in any browser. No install or build step is needed.

## Edit it
- Text and layout: `index.html` (replace every `[bracketed]` placeholder)
- Styling: `style.css`
- Links: fill in the `URLS` object near the bottom of `index.html`
- Photos: `assets/`

## Deploy on GitHub Pages
1. Create a new public repository on GitHub (e.g. `portfolio`).
2. Upload all files in this folder, keeping `index.html` at the top level.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder to **/ (root)**, then **Save**.
5. After a minute or two your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.

Tip: name the repository `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.
