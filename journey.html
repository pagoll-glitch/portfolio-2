2026 • The Spark & First Lines

Discovered the Joy of Programming

+

Wrote my first Python programs at Newton School of Technology. I remember watching terminal outputs respond to inputs and realizing that software engineering is essentially digital alchemy: turning logical thoughts into working systems.

  • Core breakthrough: Grasping condition branching, while/for loops, and function decomposition.
  • Initial obstacle: Debugging off-by-one errors and understanding variable scope.
  • Takeaway: Code isn't about memorization; it's about breaking big intimidating problems into bite-sized truths.
2026 • The First Web Build

PathFinder • Student Career Platform

+

Moved beyond simple terminal scripts to build a real browser application. I wanted to help peers who were paralyzed by too many career options.

  • Architecture: Avoided heavy external dependencies; used semantic HTML5, pure CSS Grid, and vanilla JavaScript.
  • Design Focus: Engineered an interactive quiz engine that generates customized 3-phase study roadmaps.
  • Key Milestone: First time seeing friends open a link and genuinely use something I had designed and written.
2026 • Smart India Hackathon

UrbanPulse AI • Team Rubix

+

Collaborated with Team Rubix on Problem Statement ID 26124 for SIH 2026. Designed a system transforming public transit buses into mobile road sensors.

  • Tech Exposure: Learned how YOLOv8 object detection runs on video frames to spot potholes and road divider damage.
  • GIS Integration: Explored GPS coordinate tagging, PostGIS spatial databases, and municipal dashboards.
  • Team Collaboration: Experienced fast-paced hackathon ideation, division of labor, and presentation preparation.
