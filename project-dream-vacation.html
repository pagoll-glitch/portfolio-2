Project 02 • Creative Web Guide

Dream Vacation • An Editorial Journey Through Paris

A multi-page cultural guide exploring Parisian landmarks, architectural history, and French gastronomy. Designed with editorial magazine typography, responsive CSS Grids, and authentic imagery.

Project Role Frontend Designer & Developer
Timeline First Year • 2026
Key Stack Multi-Page HTML5, CSS Grid, Typography
Domain Travel • Food • Cultural Heritage

Overview & Inspiration

Paris has always fascinated me with its effortless union of historical grandeur, street-level warmth, and artistic rebellion. I created Dream Vacation • Paris as a web development project to celebrate that spirit through responsive web craftsmanship.

Instead of building a sterile bullet-point directory, I envisioned the site as a digital travel magazine: rich photographs of grand boulevards paired with intimate explorations of neighborhood boulangeries, golden croissants, and warm crêpes.

My Design & Technical Approach

I structured the project across dedicated, interconnected pages: a comprehensive homepage introducing the history and allure of Paris, followed by curated deep-dives into iconic monuments and French culinary treasures.

The typography uses clean modern sans-serifs for readability, paired with elegant serif accents that echo traditional Parisian bookstore prints and café menus.

Key Features

  • ✦ Monument Directory: In-depth historical summaries of the Eiffel Tower, Louvre, Arc de Triomphe, Notre-Dame, Montmartre, and Versailles.
  • ✦ French Gastronomy Pages: Dedicated culinary profiles on the history of croissants and the cultural origins of French crêpes.
  • ✦ Consistent Global Navigation: Persistent top header navigation allowing intuitive browsing across landmark and cuisine sections.
  • ✦ Fluid Responsiveness: Adaptive image grids that reorganize gracefully from wide desktop monitors to pocket smartphones.

Technologies Used

Semantic HTML5 CSS Flexbox & Grid Responsive Design (Media Queries) Modern WebP & AVIF Formats Modular File Structure

What I Learned

Design & Frontend Reflection

1. Visual storytelling creates emotion: Technology is memorable when it evokes feeling. Building this website made me realize how important layout cadence, color harmony, and imagery are in web engineering.

2. Multi-page asset management: Organizing separate HTML files, linking relative paths cleanly, and managing multiple high-resolution images taught me fundamental frontend directory hygiene.

3. Cross-device image optimization: Using modern image formats like WebP significantly improved load speeds without sacrificing visual crispness.
